# Known Limitations

The current beta is intentionally release-blocked. The canonical, evidence-backed list is
[`docs/audit/BUG_AUDIT.md`](https://github.com/kizio806/SpectraEvents/blob/main/docs/audit/BUG_AUDIT.md).

The release-critical themes are:

- reward state-machine and podium durability verification;
- shared/public loot conservation on every platform;
- clean-server bundles for all five official events;
- replacement and client verification of unfinished assets;
- complete success/failure/cancel/restart/reward/cleanup server journeys;
- real-client pack acceptance;
- truthful public beta metadata.

The executable register is
[`config/release/release-blockers.json`](https://github.com/kizio806/SpectraEvents/blob/main/config/release/release-blockers.json).
Missing evidence is a blocker, not implicit success.
