## [1.0.0]

### Added
- **Initial Release of SpectraEvents**: Next-generation, data-driven 3D event engine for Paper, Purpur, Folia, and Spigot servers.
- **Synchronized Versioning Architecture**: Synchronized Semantic Versioning with Minecraft compatibility build metadata (`1.0.0+mc26.x`).
- **Standardized Multi-Platform Distribution Artifacts**: Dedicated distribution JAR outputs for `spectra-events-1.0.0-mc26.x-paper-purpur-folia.jar` and `spectra-events-1.0.0-mc26.x-spigot-bukkit.jar`.
- **Purely Event-Driven 3D Kernel**: High-performance, data-driven event execution with customizable YAML definitions for Metin, Meteor, Airdrop, Piñata, and Boss Portal.
- **Folia Multithreading**: Native Folia region multithreading support via `RegionTaskScheduler` with zero data races.
- **Full Platform & Integration Parity**: Seamless third-party plugin integration (Vault, LuckPerms, WorldGuard, PlaceholderAPI, Nexo, Oraxen, ItemsAdder) across both Paper and Spigot.
- **Interactive Admin GUI**: Comprehensive 17-screen administrative interface with session navigation, pagination, and administration subcommands.
- **High-Fidelity Client Resource Packs**: Version-specific client resource pack delivery for Minecraft 26.1, 26.2, and 26.3.
- **Strict Quality & Testing Standards**: Spotless formatting, ArchUnit architectural boundaries, and extensive test coverage.
