| Version | Supported          |

## Reporting a Vulnerability

We take the security of SpectraEvents seriously. If you discover a security vulnerability, please report it via GitHub Security Advisories:

1. Navigate to the repository's [Security Advisories](https://github.com/kizio806/SpectraEvents/security/advisories).
2. Click **Report a vulnerability**.
3. Provide details about the issue, impact, and steps to reproduce.

Please do not open public GitHub issues for security vulnerabilities. We will respond to advisory submissions promptly and work on a fix before public disclosure.
