```markdown
# ✨ SpectraEvents

**SpectraEvents** is a next-generation, data-driven **3D event engine** for modern Paper and Spigot servers. Powered by native Display and Interaction entities, keyframed timeline animations, and flexible YAML definitions, it brings stunning animated community events to your server without client-side mods!

---

## 🌟 Key Features

- 🎭 **Native 3D Models:** Renders smooth, multi-bone Blockbench models directly using vanilla Display entities (`item_display`, `block_display`). No client mods required!
- 🎬 **Keyframed Timelines:** Fluid timeline-driven bone animations with easing (linear, ease-in, ease-out, slerp quaternion rotations).
- 📜 **100% Data-Driven:** Define complete multi-phase events, raids, boss fights, loot drops, and pinatas entirely in YAML.
- 📬 **Durable Mailbox Rewards:** Transactional, crash-safe reward delivery (`PENDING -> DELIVERING -> DELIVERED`) stored in high-performance SQLite WAL persistence.
- ⚡ **Paper & Spigot Parity:** Dedicated, optimized distribution JARs for both Paper (with Folia region scheduling) and Spigot platforms.
- 🛠️ **In-Game Administration:** Built-in operator tools (`/spectraevents doctor`, `/spectraevents status`, definition validator, and template installer).
```
