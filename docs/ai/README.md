# AI / Engineering Context

This directory contains durable engineering context for humans and AI agents.

- `PROJECT_CONTEXT.md` — what SpectraEvents is and why it exists
- `ARCHITECTURE.md` — module boundaries and dependency direction
- `ENGINEERING_RULES.md` — coding and design constraints
- `TESTING.md` — testing strategy and quality requirements
- `WORKFLOW.md` — expected engineering workflow
- `PROJECT_STATE.md` — current development state and next milestone

`AGENTS.md` is the canonical entry point. Tool-specific instruction files only point into this
system and do not define competing architecture.
