# SpectraEvents 1.0.0 — Minecraft 26.x

**Initial release of SpectraEvents** — a next-generation, data-driven 3D event engine for Paper, Purpur, Folia, and Spigot servers running Minecraft 26.1–26.3.

---

## 🚀 Highlights

This release establishes the authoritative repository-wide versioning architecture (`1.0.0+mc26.x`). The codebase features robust architectural consolidation, quality hardening, and full platform parity. All quality gates pass cleanly, and the hexagonal architecture is fully established.

---

## ✨ Features & Capabilities

### Architecture & Platform Support
- **Multi-Platform Distribution Artifacts**: Dedicated production distributions for `paper-purpur-folia` and `spigot-bukkit`.
- **Full Integration Parity**: Seamless integration with Vault, LuckPerms, WorldGuard, PlaceholderAPI, Nexo, Oraxen, and ItemsAdder across both Paper and Spigot.
- **Unified 3D Model & Animation Engine**: Data-driven vector, Euler rotation, and quaternion parsing logic via `SpecMathParser` with robust rendering pipelines.
- **Admin GUI**: Full 17-screen Admin GUI hierarchy with session navigation, pagination, and administration subcommands.
- **Comprehensive Platform Testing**: Full coverage across handle management, entity reconciliation, scheduling bootstrap, and GUI text components.

### Reliability & Concurrency
- **Folia Multithreading**: Native region scheduling and thread safety using Folia `RegionTaskScheduler`.
- **Thread-Safe Data Handling**: Lock acquisition, double-checked state validation, and atomic queue tracking in persistence executors.
- **Strict Quality Gates**: Spotless formatting, Checkstyle validation, ArchUnit architectural boundaries, and extensive test coverage.
