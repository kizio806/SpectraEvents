# SpectraEvents 0.1.1-beta.2

Release date: 2026-11-03
Channel: Beta
Java: 25
Environment: Dedicated server

## Beta status

This is a public beta release of SpectraEvents. Its purpose is to deliver the production-hardened
multi-platform event engine, verified asset pipelines, and complete Spigot/Folia feature parity.
Operators should test on a staging server and maintain backups of their SQLite data (`spectraevents.db`)
before updating production servers.

## Downloads and compatibility

SpectraEvents release automation compiles **exactly two production distribution JARs** adhering to the

| Distribution Artifact | Server Platform Families | Minecraft Line | Modrinth Version Entry | Features & Scheduling |

> - Use the **Paper artifact** (`SpectraEvents-<version>-paper.jar`) on **Paper**, **Purpur**, or **Folia** (Minecraft 26.1–26.3). Folia is fully supported with native region-aware multithreading.
> - Use the **Spigot artifact** (`SpectraEvents-<version>-spigot.jar`) on **Spigot** or **CraftBukkit** (Minecraft 26.1–26.3).

## Highlights

- **Admin GUI Portability & Spigot Feature Parity:** The entire Admin GUI hierarchy (17 screens, session navigation, pagination) is relocated to `:platforms:bukkit:gui` with `GuiText.legacy` component bridging. Spigot receives the full modular administration command suite (`/spectraevents location`, `model`, `asset`, `integration`, `update`, `admin`).
- **3D Model Renderer Deduplication:** Extracted `AbstractBukkitModelRenderer` into `:platforms:bukkit:render`, eliminating ~800 lines of duplicate Display/Interaction entity math and PDC persistence while maintaining Folia regional multithreading.
- **Folia 26.1–26.3 Full Support:** Native region-aware scheduling foundation (`RegionTaskScheduler`, `PaperRegionTaskScheduler`) with BossBar HUD fallback across all Folia releases.
- **Static Analysis & Hygiene Hardening:** Zero compiler warnings (`-Werror -Xlint:all`), zero `@SuppressWarnings`, and zero blanket SpotBugs/PMD suppressions. Typed domain exceptions (`FatalActionException`, `IllegalStateException`) replace generic runtime catches.
- **Transactional Mailbox:** Crash-safe reward delivery (`PENDING -> DELIVERING -> DELIVERED`) stored in high-performance SQLite WAL mode with single-writer thread containment.
- **Toolchain Modernization:** Gradle 9.8.2 and JaCoCo 0.8.15 with strict dependency lockfile synchronization.
