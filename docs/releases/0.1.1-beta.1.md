# SpectraEvents 0.1.1-beta.1

Release date: 2026-10-04
Channel: Beta
Java: 25
Environment: Dedicated server

## Downloads and compatibility

| Server | Minecraft | File | Modrinth metadata |
| --- | --- | --- | --- |
| Paper, Purpur | 26.1–26.3 | `SpectraEvents-0.1.1-beta.1-paper.jar` | Paper and Purpur, 26.1–26.3 |
| Folia | 26.1–26.2 | `SpectraEvents-0.1.1-beta.1-paper.jar` | Separate Folia version, 26.1–26.2 |
| Spigot, CraftBukkit | 26.1–26.3 | `SpectraEvents-0.1.1-beta.1-spigot.jar` | Spigot and Bukkit, 26.1–26.3 |

Folia 26.3 is intentionally not supported by this beta. The Paper-family JAR refuses startup on
that runtime before initializing SpectraEvents or touching event data, and tells the operator to
install a newer release when support returns.

## Resource packs

Release automation publishes three independent client ZIPs to the separate SpectraEvents Assets
Modrinth project. They are not interchangeable:

| Client release line | File | Modrinth version |
| --- | --- | --- |
| 26.1 | `spectraevents-profile_26_1.zip` | `0.1.1-beta.1+26.1` |
| 26.2 | `spectraevents-profile_26_2.zip` | `0.1.1-beta.1+26.2` |
| 26.3 | `spectraevents-profile_26_3.zip` | `0.1.1-beta.1+26.3` |

The server selects the release-line-matching pack when an administrator configures the official
Modrinth resource-pack project in `resource-pack.yml`. Delivery remains disabled by default; enable
it only after real-client acceptance has been recorded for the exact hosted ZIP and client profile.

## Highlights

- Fresh install → bundled Metin template → validation → start → restart recovery is covered by a
  real-server workflow.
- All five reference definitions use the shared data-driven engine and have focused lifecycle and
  cleanup regression coverage.
- Bundled Blockbench sources are validated as vanilla-compatible cuboid geometry before startup.
- Resource-pack generation and the three release profiles are deterministic.

## Verification

The release candidate passed `./gradlew clean check build`, release-artifact checks, all three
resource-pack profile builds, and fresh-install/recovery runtime workflows for Paper/Purpur 26.1–26.3,
Folia 26.1–26.2, and Spigot/CraftBukkit 26.1–26.3.
