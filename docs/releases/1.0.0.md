# SpectraEvents 1.0.0

**First stable release of SpectraEvents** — a next-generation, data-driven 3D event engine for Paper, Purpur, Folia, and Spigot servers running Minecraft 26.1–26.3.

---

## 🚀 Highlights

This release marks the transition from public beta to stable. The codebase has undergone extensive architectural consolidation, quality hardening, and platform parity work since the last beta. All known bugs are resolved, all quality gates pass cleanly, and the hexagonal architecture is fully established.

---

## ✨ What's New Since 0.1.1-beta.2

### Architecture & Code Quality
- **Paper Command Parity**: Extracted `ScheduleCommandHandler` and `RewardsCommandHandler` in `:platforms:paper:common:command`, achieving full architectural symmetry with Spigot.
- **Spec Math Deduplication**: Extracted `SpecMathParser` eliminating identical 3D vector, Euler rotation, and quaternion parsing logic duplicated between `ModelCompiler` and `AnimationCompiler`.
- **Model Transform Deduplication**: Generalized `applyTransformTeleports` in `AbstractBukkitModelRenderer`, eliminating duplicated entity traversal and handle mapping between Paper and Spigot (~800 lines removed).
- **Full Integration & Custom Item Parity**: Relocated third-party plugin integrations (Vault, LuckPerms, WorldGuard, PlaceholderAPI, Nexo, Oraxen, ItemsAdder) to `:platforms:bukkit:integration` with 100% parity across Paper and Spigot.
- **Shared Entity Reconciler & Model Handles**: Unified `BukkitModelInstanceHandle` and `AbstractBukkitEntityReconciler` in `:platforms:bukkit`, eliminating duplicate chunk scanning and corrupted entity handling.
- **Shared Schedule Bootstrap**: `BukkitScheduleBootstrapHelper` deduplicates YAML schedule loading across both platform bootstraps.
- **Admin GUI Portability**: Relocated 17-screen Admin GUI hierarchy to `:platforms:bukkit:gui` with Spigot compatibility bridging. Added modular Spigot admin subcommands achieving 100% feature parity with Paper.

### Platform Tests
Added unit tests for: `BukkitModelInstanceHandleTest`, `AbstractBukkitEntityReconcilerTest`, `BukkitScheduleBootstrapHelperTest`, `BukkitIntegrationManagerTest`, `SpigotBossBarManagerTest`, `BukkitBossBarHolderTest`, `BukkitBossBarProgressCalculatorTest`, `GuiTextTest`, `CommandTextTest`, `SpigotUpdateCommandHandlerTest`, `SpigotAssetCommandHandlerTest`.

### Fixes
- **Resource Pack Status Mapping on Spigot** (`SE-BUG-01`): Corrected handling of `DOWNLOADED`, `INVALID_URL`, `FAILED_RELOAD`, and `DISCARDED` statuses in `AbstractBukkitPlayerResourcePackAdapter`, preventing erroneous player kicks.
- **BossBar Progress Reset Bug**: Resolved `SpigotBossBarManager` concurrency hazard where boss bar progress was reset to 1.0 on every HUD refresh.
- **Spigot Plugin Lifecycle**: Hardened `SpectraEventsSpigotPlugin` with safe shutdown and audience teardown on startup failure.
- **Thread-Safe Item Providers**: `CopyOnWriteArrayList` in `AbstractBukkitActionAdapter` and atomic peak queue depth tracking in `SingleWriterPersistenceExecutor`.

### Security
- **TOCTOU Race Condition**: Resolved in `AnimationRuntimeService` via strict lock acquisition and double-checked registration state.
- **SHA-1 Cryptographic Contract**: Resolved CodeQL alert in `ResourcePackBuilder` with explicit protocol-mandated hash method.
- **Encapsulation Hardening**: Defensive copies (`List.copyOf`) in `EngineContext` and `SpectraAssetFace` eliminating internal representation leaks.
- **Zero CodeQL Alerts**: All 38 previously identified CodeQL alerts resolved across domain, platform, and test modules.

### Project
- Added official SE project icon (128×128 plugin icon, 1024×1024 for Modrinth/GitHub).
- Fixed compatibility badges in README to correctly show `26.1–26.3` (was incorrectly `26.3` only).
- SonarCloud Quality Gate: **Rating A, 0 open issues**.
