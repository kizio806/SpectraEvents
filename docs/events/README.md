# Event Specifications

This directory contains the reference specifications for various event types that SpectraEvents aims to support.

These specifications act as design blueprints to ensure the engine primitives (phases, triggers, components, etc.) are sufficiently flexible.

## Index

- [Event System Overview](event-system.md): Describes the core event lifecycle vs. configuration phases.
- [Meteor](meteor.md): A falling, high-health object with damage-based ranking.
- [Airdrop](airdrop.md): A falling loot crate opened via interaction (no health).
- [Metin](metin.md): A stationary object that spawns mobs at health thresholds.
- [Pinata](pinata.md): A stationary object broken by a set number of discrete hits.
- [Vault](vault.md): A multi-stage interactive hacking/looting event.
- [Boss Portal](boss-portal.md): An area control and boss spawning event.
