# Modrinth Resource-Pack Delivery

Status: **deferred / not composed into a distribution**.

The repository contains prototype source adapters, but the beta neither publishes an official asset
pack nor resolves and sends one to players. This document intentionally records no active runtime
contract.

A future implementation must be introduced through an ADR and prove exact version selection,
allowlisted HTTPS redirects, bounded downloads, SHA-256 verification, atomic cache replacement,
rate-limit behavior, and player accept/decline/failure flows before public claims are restored.
