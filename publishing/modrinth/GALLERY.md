# Modrinth gallery plan

Do not upload prototype, invisible, source-editor-only, or unverified renders. Each image needs a
descriptive title and alt-like description.

| Order | Featured | Required image | Suggested title | Description content |
| ---: | :---: | --- | --- | --- |
| 0 | Yes | In-client five-event montage | `Five events, one reusable engine` | Name the visible events and exact client/profile used |
| 1 | No | Airdrop gameplay | `Contested Airdrop` | Arrival, shared chest, player count, and server version |
| 2 | No | Meteor gameplay | `Meteor raid` | Health/waves/public loot and tested platform |
| 3 | No | Metin gameplay | `Metin encounter` | Model, phase, contribution UI, and tested platform |
| 4 | No | Piñata gameplay | `Piñata frenzy` | Hit progress, frenzy mechanic, and tested platform |
| 5 | No | Boss Portal gameplay | `Boss Portal finale` | Portal, boss/enrage phase, and tested platform |
| 6 | No | Operator authoring/GUI | `Data-driven administration` | YAML validation or real admin interface without mockups |

Prefer lossless PNG or high-quality WebP within Modrinth's current 5 MiB gallery limit. Record the
source candidate commit, client version, pack SHA-1, and permission to publish alongside each image.
